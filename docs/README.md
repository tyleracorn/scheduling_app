# Cabin Scheduling — Documentation

Lightweight shared-cabin scheduling for ~10 co-owner households. Calendar-first draft picks, coordinator assignment, publish, swaps, notes, and green/red sharing indicators. Self-hosted via Docker (NAS-friendly).
